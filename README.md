# web-style-guide

Personal clone of the style-guide starter set. This repo includes three design-system directions that can be used as a base for a brand or website build.

## Included kits

- `starter-paper` — calm editorial style
- `starter-clay` — warm friendly type
- `starter-signal` — bold technical style

Use each folder as a self-contained starter kit, then customize the tokens and component styles for your brand.
